# Active Learnings — Heuristic Learning Snake

> 最近更新: 2026-05-08

## 策略优化方法论

### 渐进式任务分解
- 将复杂优化拆成独立可验证的小步（BFS → 尾巴追踪 → 冲刺优化）
- 每步设定明确得分阈值（30→50→80→100），便于定位回归
- 避免一次改太多导致难以调试

### 二阶安全检查
- 贪心策略的常见陷阱：只看当前收益不看后果
- "能否到达食物" 不等于 "吃完食物后是否安全"
- 模拟吃完食物后的状态（尾巴不移走、蛇增长）做二次评估

## 动态系统评估

### 洪水填充的时间维度
- 标准 flood_fill 不考虑蛇身移动释放的空间，长蛇场景下评估偏低
- `flood_fill_with_tail` 通过 body_list 索引 + BFS 步数，允许已移走的身体段被穿过
- 核心洞察：`body_list[i]` 在 `(i+1)` 步后移走，BFS 到达时若 `steps >= i` 则可通过

### 尾巴感知的安全移动
- 尾巴本步会移走，因此移向尾巴位置是安全的
- `safe_body = body_set - {tail}` 扩大了安全候选集

## 极端情况处理

### 高占用率保命模式
- 蛇身超过网格 60% 时，切换到纯生存模式（只选空间最大方向）
- 此时追食物的风险远大于收益
- 动态评估（flood_fill_with_tail）在此模式下比静态评估更准确
